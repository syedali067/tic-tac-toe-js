# Tic Tac Toe 🎮

A simple and interactive 2-player Tic Tac Toe game built using HTML, CSS, and JavaScript.

---

## 🚀 Features
- 2 Player Game (X and O)
- Win detection logic
- Draw detection
- Reset game functionality
- Interactive and responsive UI

---

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
